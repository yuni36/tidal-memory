# 功能一览

Tidal 是**单用户**自托管伴侣：一个连接密钥，一套数据，不面向多租户。

最小可用 / 推荐基线 / 完整的定义见根目录 [`README.md`](../README.md)；本文只讲“有什么、需要什么、不配会怎样”。

---

## 功能矩阵

| 能力 | 需要什么 | 不配会怎样 |
|---|---|---|
| 聊天 | 1 个聊天 Key（Gemini 原生或 OpenAI 兼容） | 不能聊 |
| 记忆 | 记忆 Key + Chroma | 只聊天，不成星 |
| 星图 | 随记忆库 | 记忆仍在，少一个视图 |
| 积温 | 主动来找只要聊天 Key；分析用 Gemini flash lite（免费层，需开“启用情绪分析”） | 仍会按静默来找；但不分析情绪、聊天不注入情绪变化 |
| 搜索 | Gemini Key + 代理 | 只能靠模型知识 |
| 推送 | 无域名：页面内提醒；锁屏要 HTTPS / 域名 | 打开页面看回复 |
| 摘要 | DeepSeek（记忆 / 事件线） | 少短期整理 |

积温 / 推送的完整口径：[`notifications.md`](notifications.md)。

## 核心能力

- **聊天中继**：消息进 SQLite，经 SSE 给大脑，再推回前端。
- **双通道大脑**：设置里单选 **Google 原生 Gemini** 或 **OpenAI 兼容**（DeepSeek 等）；换路不丢记忆库。
- **记忆流水线**：静默或积压触发提取 → 整理归星 → 对话时可检索 / 注入（注入可关）。
- **短期整理（可选）**：航海日志、今日事件线——与长期星座分开，失败不挡主聊。
- **积温（可选）**：数学时钟 + 可选五轴分析 + 语调；可驱动主动开口。详见 [`notifications.md`](notifications.md)。
- **天气 / 日程 / 自醒（可选）**：设置页独立开关；关 = 不注入、不调对应模型。
- **联网搜索**：仅 Gemini 路径可挂 Google Search grounding；详见 [`../ops/usage-apis.md`](../ops/usage-apis.md)。

## 本开源树明确不做 / 不强调

- 主动通知文档与产品口径**只讲积温**（旧「骰子」随机问候不作为开源推荐路径）。
- 内置壁纸只保留珍珠与海港；夜色 Mood 包不进公开树。见 [`wallpaper.md`](wallpaper.md)。
- 语音来电 / TTS：本树不开语音网关。

## 旁路原则（记住这一句）

可选能力没配 Key、报错或关掉 → **只是该能力没有**；聊天一问一答仍应可用。

积温也是旁路：没有 affect API 仍会按静默主动来找；主动来找本身用聊天模型，计入主聊。
